# Baseline privada — 2026-07-29

Esta baseline registra o estado atual do NeoEng-D-Trace sem importar o histórico Git local anterior.

## Escopo preservado

- código em `src/` e entrada `app.py`;
- suíte ativa em `tests/`;
- testes históricos isolados em `quality/legacy_tests/`;
- documentação, benchmarks e ferramentas de manutenção;
- workflow privado de validação no GitHub Actions;
- configuração de exemplo sem caminhos pessoais;
- versões diretas das dependências capturadas do ambiente Windows/Python 3.11.

## Conteúdo deliberadamente excluído

- `.git/` anterior;
- `.venv/` e qualquer ambiente virtual;
- `backup/` e snapshots duplicados;
- caches Python, Pytest e cobertura;
- arquivos `*.backup`, arquivos compactados e exportações GLB locais;
- `config.json` e caminhos pessoais;
- relatórios gerados, contexto para IA e arquivos temporários;
- testes avulsos fora da suíte oficial `tests/`.

## Validação executada antes da publicação

- inventário e busca de caminhos pessoais/segredos no conteúdo preservado;
- compilação de `app.py`, `src/`, `tests/`, `tools/` e `bench/`;
- testes não gráficos executados no ambiente Linux disponível;
- verificação do manifesto SHA-256 com `python tools/baseline_integrity.py --verify`.

A validação nativa completa da interface continua dependente de Windows, Python 3.11 e PySide6. O GitHub Actions é o portão remoto para a suíte integral.

## Limitações conhecidas preservadas

Esta baseline não declara o produto como comercialmente pronto. Permanecem abertas, entre outras:

- persistência incompleta do projeto e ausência do fluxo completo Abrir/Salvar na UI;
- Undo/Redo incompleto para movimentação de vértices;
- fluxo inconsistente de exportação de colisões na interface;
- validação insuficiente de alguns argumentos headless;
- baixa cobertura em módulos de UI e ferramentas interativas;
- exportação GLTF/GLB sem UV, material ou textura.

Essas limitações são registradas para impedir que o primeiro commit seja interpretado como uma release final.

## Integridade

`baseline_manifest.json` contém tamanho e SHA-256 de cada arquivo da baseline, exceto o próprio manifesto. Para validar:

```powershell
python .\tools\baseline_integrity.py --verify
```

Para atualizar o manifesto após uma alteração deliberada:

```powershell
python .\tools\baseline_integrity.py --write
python .\tools\baseline_integrity.py --verify
```
