# Checkpoint funcional — Etapa 0.5.2D

Este checkpoint representa o estado aprovado manualmente no Windows antes das alterações experimentais e corretivas da Etapa 0.5.2E.

## Regra

A Etapa 0.5.2E deve poder ser revertida integralmente para este estado. O arquivo `quality/checkpoints/0.5.2d_manifest.json` registra os hashes SHA-256 dos arquivos funcionais que serão tocados.

## Estado confirmado pelo usuário

- criação e seleção automática de polígonos funcionando;
- lista lateral sincronizada;
- diálogo de exportação compactado;
- PNG, atlas, metadados de engines e GLTF preservados;
- aplicativo abrindo e fechando normalmente.

## Limite

Este checkpoint não é ainda o baseline Git final do projeto. Ele é um ponto de restauração funcional específico para a Etapa 0.5.2E.
