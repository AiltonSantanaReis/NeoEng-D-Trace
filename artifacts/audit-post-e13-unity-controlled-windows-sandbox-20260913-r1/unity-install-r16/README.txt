Windows Sandbox r16 — montagem persistente da instalação do Unity

Este diretório é mapeado exclusivamente para o Windows Sandbox como C:\UnityInstall
com escrita permitida, para que uma instalação manual do Unity Hub não seja perdida
quando a VM descartável for encerrada.

No Hub dentro do Sandbox, selecione C:\UnityInstall como destino do Editor antes de
iniciar a instalação. O Unity não é executado nativamente no host por este harness.
